# 量衡 仪器测量处理

管理仪器、通道、单位、校准证书、观测和测量活动。处理过程保留原值与修订信息，窗口统计、通道对照和快照导出可追溯到输入。

测量模型模块把多路仪器读数合成为可版本化的指标：输入带单位并关联观测与校准证书，表达式支持线性组合、乘除和整数幂，注册时校验量纲、依赖循环和非法运算。随机误差、共享系统误差（同一参考标准产生的相关性）和显式相关矩阵全部留档；矩阵不对称、非半正定或量纲不匹配时拒算。报告给出合成值、灵敏度、各误差与协方差贡献、标准不确定度和指定覆盖因子的扩展不确定度，并明确区分覆盖因子与置信水平。非线性模型可用固定种子抽样核对，记录分布、无效样本和与一阶结果的差异。证书更正只产生新报告，旧报告保持不变。

## 运行环境

使用 Python 3.11，核心功能依赖标准库和 SQLite。演示和测试只使用本地合成数据，不需要账户、设备或外部运行服务。请从项目根目录执行命令。

## 检查与运行

构建检查验证语法，测试使用临时数据目录，不会连接远端服务。

```sh
python3 -m compileall -q metrology
python3 -m unittest discover -s tests -v
python3 -m metrology demo
```

演示会展示产品的实际数据处理和输出，运行结束自行退出。查看现有接口：

```sh
python3 -m metrology --help
```

## 测量模型与不确定度

模型通过 JSON 动作文档使用，典型动作包括 `model_register`、`model_evaluate`、`model_report`、`model_reports`、`model_correction` 和 `model_certificate_reports`。

- 表达式只接受输入名、数值常量、加减乘除和整数幂（`^`），函数调用、比较、位运算和非整数幂在解析时拒绝。
- 模型按内容指纹版本化：相同内容复用既有版本，内容变更产生新版本，历史版本持续可读；输入可声明来源模型，注册时检测依赖循环。
- 每个输入记录观测标识、校准证书、随机标准不确定度和共享系统效应链接；系统效应可被多个输入引用，自动生成协方差项。
- 显式协方差矩阵必须与输入数量一致、对称、半正定，且非零条目两侧量纲匹配，否则评估拒绝执行。
- 报告中的覆盖因子 `k` 仅按请求记录，文案明确说明它不是置信水平，也不声称覆盖概率。
- `monte_carlo` 段携带固定种子和样本量，输出均值、标准差、中位数、2.5/97.5 百分位、无效样本清单以及与 GUM 一阶结果的差异；相同种子产生完全一致的分布。
- 证书更正使用 `model_correction` 另出报告，新报告通过 `supersedes` 指向旧报告；旧报告不可变，重复报告标识会被拒绝。

## 目录与数据

metrology/ 保存领域逻辑和请求入口，tests/ 包含正常行为、边界与恢复测试。例子中的标识和记录为合成资料，不包含真实人员或生产测量。业务目录和本地数据库由调用者指定，应与源码分开保存。

## 干净环境复现

容器定义固定运行时版本。构建时准备环境，运行时无需网络；每次启动会复制只读源码到临时工作目录，测试产生的文件不会写回仓库。

```sh
docker build -t local-product-check .
docker run --rm --network none local-product-check
```
